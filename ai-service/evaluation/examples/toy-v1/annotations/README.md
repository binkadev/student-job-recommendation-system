# Synthetic Annotation Packets

These two completed packets contain synthetic labels created only to test the annotation review and manual-adjudication workflow. `judgments.adjudication.synthetic-completed.csv` is a separate fixture representing labels filled manually after the synthetic disagreements were inspected.

They are not annotations from real users, are not evidence of recommendation quality, and must not be reported as experimental results. The packets intentionally contain both unanimous pairs and disagreements.
