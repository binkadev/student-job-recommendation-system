## Evidence and status meanings

This is a route inventory and a focused source/contract audit, followed by fixes to Student profile writes, recommendation evidence, Company reports and misleading unsupported capabilities. It is **not** certification of every feature or a complete security audit.

- **REAL**: working behavior proven against its required runtime/persistence. No Backend-dependent flow is promoted to REAL by this session's mocked HTTP tests.
- **PARTIAL**: source has actual Backend calls, but a recorded gap remains.
- **UI_ONLY**: screen/alias exists without the advertised business operation.
- **UNSUPPORTED**: Backend intentionally rejects the operation or no supporting module/API/schema was found.
- **BROKEN**: an evidenced contract/business error, with before/after recorded below.
- **NOT_VERIFIED**: insufficient test/runtime evidence; this applies independently of implementation status.

All Backend-dependent inventory rows below have **live persistence, authorization and cross-role E2E = NOT_VERIFIED** in this session. “API thật” identifies executable controllers and services, not a claim of live success.

Read sources: `AGENTS.md`, `docs/datn/CODEX_GUARDRAILS.md`, README, V3 contract, relevant API/schema/status/verification documents; router, route constants and menus; Student/Company/Public pages, services and hooks; matching Backend controllers, DTOs, services, security configuration and relevant migrations. Some older status documents refer to historical commits/V16 and do not establish current functionality.

Backend module base is `backend/src/main/java/com/tttn/jobrecommendation/modules/` (the executable source uses modules; do not infer a flat controller directory). API paths in the table are relative to the `/api` prefix configured by Axios.

Verification keys: **U** = automated unit/component tests with mocked HTTP; **S** = static source/contract review; **L** = live flow plus reload, including negative permissions; **V** = visual/keyboard review at 375, 430, 768, 1024, 1440px. L and V remain pending.

## Fixed in this batch

1. **Profile corruption (P0):** removed lossy structured editor serialization. The Backend's multiline education/experience/projects are now edited and displayed directly as text; university/major/graduation year remain separate scalar fields. A repeated save no longer injects “Thông tin hồ sơ”, “Cập nhật từ backend” or duplicate headings into stored content.
2. **Wrong profile field mapping (P0):** headline no longer overwrites targetPosition; current location no longer overwrites preferredLocation. Empty strings follow existing Backend clearing semantics. No new API/DB fields were invented.
3. **Invalid/unreported writes (P1):** removed the save-section validation bypass; one validated save path, pending disable/ref guard, field focus/error summary, draft retention on failure and truthful partial-save/reload errors. Skill-only changes are counted as unsaved. Preferences now handle errors and can clear supported text fields.
4. **Invented recommendation claims (P0):** explanation comes only from Backend reason/explanation. Empty evidence no longer becomes “Không thiếu kỹ năng bắt buộc”; UI does not recompute a coverage denominator from current public job skills. Global rank no longer falls back to tier rank. Existing tier scores/order remain unchanged.
5. **Report scope (P1):** exclude other companies' ACTIVE jobs before reporting; explain loaded records versus available totals, label application counts correctly, refresh and retry. The report remains PARTIAL because it intentionally uses bounded existing list APIs.
6. **Unsupported capability UX (P1):** interview/member/invitation/message screens explain missing functionality; remove invented membership roles and false empty inbox/schedule claims. Company message links stay in Company routes. Privacy/custom pipeline/email templates no longer offer controls that cannot persist; 2FA is described as unsupported.
7. **Home data truth (P1):** use canonical statistics DTO; preserve actual zero, show unknown on invalid/missing/error, offer retry, avoid successful empty-list messages on failure. A missing company openJobs count is unknown rather than zero.
8. **Password recovery:** removed the success toast and forms that did not call any recovery API. Forgot/reset routes now explicitly explain the unsupported capability.
9. **Clipboard feedback:** profile copy success requires an actual successful Clipboard write; rejected/unavailable Clipboard reports failure.
